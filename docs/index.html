Panorama wallpapers

One image. Every display.

Spanorama is a free, open-source macOS app that spans one panorama across all your displays and places every image exactly where you want it — applied at native Retina quality, pixel-perfect down to the seam.

Pipeline

How the seam stays invisible.

macOS sets desktop pictures per display and stops there. Spanorama works with that, not against it.

Retina renders at 2×. Each slice is written to its own temp PNG and set with NSWorkspace, one image pixel per screen point — that is why the seam lands exactly on the bezel. Display origins can be negative: screens left of or above the main display sit at x < 0.

Install

Two ways in. Both free.

Download the app

Grab the latest bundle from GitHub Releases. It is ad-hoc signed, not notarized — on first launch, right-click the app and choose Open, or clear the quarantine flag:

xattr -cr dist/Spanorama.app

Download v0.1.0 — macOS 14+

Build from source

Plain Swift Package Manager — the Command Line Tools alone can build it, full Xcode not required. Run the test suite with swift run SpanoramaTests.

git clone https://github.com/USERNAME/Spanorama.git
cd Spanorama
./Scripts/build-app.sh release   # → dist/Spanorama.app
